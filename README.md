## How to use it

**Claude Code**
Copy a skill folder from `skills/` into `~/.claude/skills/` (all your projects)
or `.claude/skills/` (one project). Claude picks it up automatically and
uses it when your request matches the skill's description.

**Claude app (claude.ai or desktop)**
Zip a skill folder and upload it in your Claude settings under skills.

**Prompts and templates**
Open the file, copy the text, paste it into any Claude conversation.
Anything in square brackets is yours to fill in.

## What's in the repo

```
skills/        Claude skills (each folder has a SKILL.md)
prompts/       Prompts you can paste into any chat
mcp/           Setups that connect Claude to other tools
templates/     Documents and structures to start from
workflows/     Step-by-step processes that combine the above
foveate/       Items that need a Foveate account (everything else doesn't)
```

Every item has its own README with what it does, how to use it, an example
of the output, and the date it was last tested.

## About Foveate

Foveate is where architects and designers build decks, run pursuits, and keep
their client book and past work in one place. Most of this toolkit works
without it. The `foveate/` folder is for people who want Claude to work
directly with their Foveate workspace.
